Here are all the commands with a brief explanation and an example:

TTN
- ttn [alphabet] [text] - converts a text to a number. There is no limit to text
- - example: ttn default Hello World

NTT
- ntt [alphabet] [number] - converts a number to a text. Number MUST be an integer type (not float)
- - example: ntt default 123456

ATN
- atn [alphabet] [text1;text2;...] - converts texts to numbers and returns their arithmetic mean. Separate multiple texts with ";"
- - example: atn default Hello;World

ATT
- att [alphabet] [text1;text2;...] - converts texts to numbers, takes their arithmetic mean, and returns it translated back into text. Separate multiple texts with ";"
- - example: att default Hello;World

HELP
- help - you are here.

EXIT
- exit | quit - kill the program

###################################################################################################

The alphabets can be any, but they must be specified in the first line. The rest are ignored. Experiment!
